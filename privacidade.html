Política de Privacidade – VoxShare

Última atualização: 26 de novembro de 2026.

1. Quais dados são usados

Ao entrar com o TikTok, o VoxShare recebe um token de acesso à conta autorizada. Ele é usado apenas para publicar os vídeos que o próprio usuário escolheu. Os vídeos, as legendas e a lista de horários ficam em arquivos no computador do usuário.

2. O que não fazemos

O VoxShare não possui servidor próprio, não coleta nem armazena dados de usuários em nenhum servidor, não vende nem compartilha dados com terceiros, e não usa cookies ou ferramentas de rastreamento. Os vídeos são enviados diretamente do computador do usuário para o TikTok.

3. Armazenamento local

O token de acesso é guardado em um arquivo local no computador do usuário, que pode apagá-lo a qualquer momento para encerrar o acesso.

4. Como revogar o acesso

O usuário pode remover a autorização do VoxShare nas configurações de segurança da conta de TikTok, em "Gerenciar permissões de apps", e apagar o arquivo de token local.

5. Alterações

Esta política pode ser atualizada. A data no topo indica a versão mais recente.
